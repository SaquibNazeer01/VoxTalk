    How to Use

    1

    Enter Your Name

    Type your name in the "Your Callsign" field so others can see who's talking.

    2

    Create or Join a Channel

    Create Channel — generates a unique 6-character code. Share this code with your friends.
    Join Channel — enter the code someone shared with you and click Join.

    3

    Allow Microphone

    When your browser asks for microphone permission, tap Allow. This is needed to send your voice.

    4

    Hold to Speak

    Press and hold the big SPEAK button to talk. Release it when you're done. On desktop, you can also hold the Spacebar.

    5

    Echo Issues?

    If you hear echo, make sure the ECHO OFF button is enabled (green). Both users should have it on.
